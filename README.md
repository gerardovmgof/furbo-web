# Furbo Web ⚽

Plataforma web para gestión de ligas de fútbol amateur: tabla de goleo, posiciones, calendario, y registro de jugadores por equipo mediante códigos.

- **Stack:** Next.js (App Router) + JavaScript + Tailwind CSS 4, deploy en Vercel
- **Equipo:** Gerardo (`gerardovmgof`) y Sebastián

## Cómo trabajar en este repo

- Nuevo en el proyecto → lee [SEBASTIAN.md](SEBASTIAN.md) (guía de arranque paso a paso)
- Las reglas de colaboración y el contexto del cliente están en [CLAUDE.md](CLAUDE.md) — Claude Code las lee automáticamente

## Desarrollo local

```bash
npm install
npm run dev   # http://localhost:3000
```

Cada push a `main` deploya automáticamente a producción en Vercel.
